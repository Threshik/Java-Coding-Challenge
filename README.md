#  Loan Management System - Java Coding Challenge

## Project Overview

This project is developed as part of the **Hexaware Technologies Foundational Training Java Coding Challenge**. It simulates a basic Loan Management System using Java, following strict object-oriented principles, user-defined exception handling, and JDBC-based database connectivity.

## 💻 Tech Stack

- **Language**: Java  
- **Database**: MySQL   
- **Architecture**: Layered (entity, dao, util, exception, main)  
- **IDE**: IntelliJ
